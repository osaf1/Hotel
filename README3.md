## Projectgegevens

### Naam van de sprint

**Sprint 3 – Database en boekingssysteem**

### Wat wil ik deze sprint maken?

Tijdens deze sprint wil ik de functionaliteit van de hotelwebsite verder uitbreiden.

Ik wil een detailpagina voor de kamers maken. De informatie en foto's van de kamers moeten vanuit de database worden opgehaald. Daarnaast wil ik ervoor zorgen dat het boekingssysteem goed werkt.

### Werkzaamheden

Tijdens deze sprint ga ik:

* Een detailpagina voor kamers maken.
* Kamerinformatie uit de database halen.
* Foto's van kamers uit de database halen.
* Meerdere foto's per kamer tonen.
* De bookingpagina verder uitwerken.
* Een `bookings` tabel maken en gebruiken.
* Boekingen opslaan in de database.
* De gebruiker en de gekozen kamer koppelen aan een boeking.
* De booking confirmation pagina verder afmaken.
* De website testen.
* Het project in GitHub bijhouden.

### Gewenst resultaat

Aan het einde van Sprint 3 wil ik een werkend boekingssysteem hebben.

De website bevat dan minimaal:

* Een detailpagina voor kamers.
* Kamerinformatie uit de database.
* Foto's uit de database.
* Een werkende bookingpagina.
* Een werkende `bookings` tabel.
* Boekingen die in de database worden opgeslagen.
* Een booking confirmation pagina.

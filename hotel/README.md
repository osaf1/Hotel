### Beschrijving van het project

Voor dit project maak ik een website voor een hotel. Op de website kunnen bezoekers informatie over het hotel bekijken, zoals de kamers, faciliteiten en contactgegevens.

Het doel is om een duidelijke en gebruiksvriendelijke hotelwebsite te maken. De website moet er professioneel uitzien en goed werken op verschillende schermformaten.

### Waarom wil ik dit project maken?

Ik wil dit project maken omdat ik mijn vaardigheden in software development verder wil ontwikkelen. Ik wil vooral meer leren over het maken van een complete website en het toepassen van HTML, CSS, JavaScript en andere technieken die nodig zijn voor een goed werkende website.

Ook wil ik leren hoe ik een project kan plannen en stap voor stap kan ontwikkelen.

### Randvoorwaarden

Bij het maken van de website houd ik rekening met de volgende voorwaarden:

* De website moet gebruiksvriendelijk en overzichtelijk zijn.
* De website moet responsive zijn voor computer, tablet en telefoon.
* De code moet overzichtelijk en goed leesbaar zijn.
* Ik gebruik geen afbeeldingen of andere content waarvoor ik geen toestemming heb.
* Ik houd rekening met **copyright** en gebruik waar nodig rechtenvrije content.
* Gebruikte libraries en frameworks moeten een passende **licentie** hebben.
* Als persoonsgegevens worden verzameld, moet ik rekening houden met de **AVG**.
* De website mag geen onnodige persoonsgegevens verzamelen.
* Ik houd rekening met toegankelijkheid en probeer de website voor zoveel mogelijk gebruikers bruikbaar te maken.
* Ik houd rekening met de maatschappelijke impact van een gebruiksvriendelijke en toegankelijke website.
